# PICARBOO — сайт-каталог авто из Кореи

Каталог всех машин с encar.com с ценой «под ключ до Владивостока», страницей авто (фото, страховая история, схема кузова, опции, расчёт цены), заявками в Telegram, входом через Telegram и админкой.

## Как считается цена

```
цена под ключ = цена на Encar (₩ → ₽ по курсу Naver «송금 받을 때»)
              + расходы по Корее и доставка до Владивостока (2 000 000 ₩ → ₽)
              + брокер, СВХ, СБКТС, ЭПТС, порт, лаборатория (100 000 ₽)
              + таможня: сбор за оформление + пошлина + утильсбор (+ акциз и НДС для электромобилей)
```

- Таможня — для физлица, личное пользование, РФ. Ставки и коэффициенты утильсбора совпадают с calcus.ru (проверено на 180 расчётах, см. `tests/customs.test.ts`). Таможенная стоимость и евро — по курсу ЦБ РФ.
- Мощность берётся из базы Naver (блок «제원»). Если комплектаций несколько — берётся максимальная (цена не окажется ниже реальной), такие модели видны в админке. Если мощность не найдена — цена скрыта до уточнения.
- Суммы 2 000 000 ₩ и 100 000 ₽, залог и стоимость осмотра меняются в админке `/admin`.
- Таблица утильсбора — `lib/pricing/util-table.ts` (2026 год; с 2027 по 2030 коэффициенты автоматически растут на 10% в год, как в графике calcus). Если государство изменит ставки — обновить таблицу и тест.

## Из чего состоит

| Часть | Где |
|---|---|
| Сайт (Next.js) | `app/`, `components/` |
| Расчёт цены | `lib/pricing/` |
| Encar: список, детали, перевод | `lib/encar/` |
| Мощность из Naver | `lib/naver/spec.ts` |
| Курсы (Naver, ЦБ) | `lib/rates.ts` |
| Фоновый процесс (обновление каталога, курсов, цен) | `worker/` |
| База данных | `db/migrations/` |

Фоновый процесс:
- курсы — раз в час, затем пересчёт всех цен;
- новые объявления — каждые 10 минут; полный проход каталога — раз в 3 часа: каталог делится по цене и пробегу на куски до 500 машин, потому что постраничная выдача Encar нестабильна. Снятые с продажи скрываются, только если обход покрыл ≥97% каталога без ошибок;
- детали машин (страховая история, лист осмотра, опции) и мощности — непрерывно.

**Первый запуск:** список (~195 000 машин) загружается за 10–20 минут, а детали — постепенно, около 1–2 суток. Машины появляются в каталоге по мере загрузки деталей, свежие — первыми.

## Запуск на сервере

Нужен любой сервер с Ubuntu 22/24: от 2 ядер, 4 ГБ памяти, 40 ГБ диска. Российский не обязателен.

| Вариант | Цена | Оплата |
|---|---|---|
| **Oracle Cloud Always Free, регион Seoul или Chuncheon** (рекомендуется) | 0 ₽ навсегда: 4 ядра ARM, 24 ГБ памяти, 200 ГБ диска | корейская или любая зарубежная карта (только для проверки) |
| Hetzner CX22 (Германия/Финляндия) | ~€4–5 в месяц | зарубежная карта |
| Vultr / AWS Lightsail, регион Seoul | ~$6–10 в месяц | зарубежная карта |

### Oracle Cloud Free — пошагово

1. Зарегистрируйтесь на oracle.com/cloud/free. **Домашний регион — South Korea Central (Seoul) или South Korea North (Chuncheon)**: сменить его потом нельзя. Корейский IP сервера ещё и удобен для Encar.
2. После регистрации переведите аккаунт на **Pay As You Go** (Billing → Upgrade). Пока вы в бесплатных лимитах, списаний нет, зато Oracle не отключит «простаивающий» бесплатный сервер.
3. Compute → Instances → Create instance:
   - Image: **Ubuntu 24.04**; Shape: **Ampere → VM.Standard.A1.Flex**, 4 OCPU, 24 GB;
   - Add SSH keys → «Generate a key pair» и скачайте приватный ключ;
   - если пишет «Out of capacity» — повторите через несколько часов или выберите другой Availability Domain.
4. Откройте порты 80 и 443: Instance → Subnet → Security List → Add Ingress Rules: Source `0.0.0.0/0`, TCP, порты `80,443`.
5. Подключитесь (`ssh -i ключ ubuntu@IP`) и откройте порты в системном фаерволе Ubuntu (в образах Oracle они закрыты):
   ```bash
   sudo iptables -I INPUT 6 -p tcp -m multiport --dports 80,443 -m state --state NEW -j ACCEPT
   sudo netfilter-persistent save
   ```
6. Дальше — общие шаги ниже (Docker, `.env`, `docker compose up`).

1. **Домен.** Купите `picarboo.ru` и в DNS создайте A‑записи `picarboo.ru` и `www.picarboo.ru` → IP сервера.
2. **Docker.** На сервере:
   ```bash
   curl -fsSL https://get.docker.com | sh
   git clone <адрес репозитория> picarboo && cd picarboo
   cp .env.example .env && nano .env
   ```
3. **Заполните `.env`:** `DOMAIN`, `POSTGRES_PASSWORD` (любой длинный пароль), `SITE_URL=https://picarboo.ru`, `ADMIN_PASSWORD`, `SESSION_SECRET` (случайная строка: `openssl rand -hex 32`), данные бота (ниже).
4. **Запуск:** `docker compose up -d --build`. HTTPS-сертификат выпустится автоматически.
5. Откройте `https://picarboo.ru/admin`, проверьте курсы и ход загрузки.

Обновление после изменений в коде: `git pull && docker compose up -d --build`.
Логи: `docker compose logs -f worker` / `docker compose logs -f web`.

### Telegram-бот (заявки и вход)

1. В Telegram откройте @BotFather → `/newbot` → получите токен. Впишите `TELEGRAM_BOT_TOKEN` и имя бота без `@` в `TELEGRAM_BOT_USERNAME`.
2. Напишите своему боту любое сообщение, затем откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — число `"chat":{"id": ...}` впишите в `TELEGRAM_ADMIN_CHAT_ID`. Заявки будут приходить вам в личку от бота.
3. Для входа через Telegram: в @BotFather → `/setdomain` → выберите бота → `picarboo.ru`.

Пока бот не настроен, сайт работает: заявки сохраняются в базе и видны в админке, VIN показывается без входа.

## Разработка

```bash
npm install
cp .env.example .env              # DATABASE_URL на локальный PostgreSQL
npm run migrate
npm run sync:once                 # один проход синхронизации (курсы, названия, новые машины, детали, мощности, цены)
npm run dev                       # http://localhost:3000
npm run worker                    # фоновый процесс постоянно
npm run check                     # lint + типы + тесты
TEST_DATABASE_URL=postgres://.../picarboo_test npm test   # с интеграционными тестами базы
```

## Ограничения, о которых нужно знать

- Данные и фото берутся с Encar через их публичный API. Encar может изменить API или ограничить доступ — тогда синхронизация остановится (в админке будет видно ошибку задачи), а сайт продолжит показывать последние данные.
- Фото загружаются напрямую с серверов Encar (на них водяной знак Encar).
- Для электромобилей таможня считает 30‑минутную мощность, а Naver даёт пиковую: такие модели помечены в админке на проверку, расчёт до проверки — по пиковой (дороже).
- Итоговые таможенные платежи определяет таможня по курсу евро на дату оформления; на сайте это указано.
